# Technology Decision Template for Codex

Use this file when Codex wants to choose, add, or change a language, framework, dependency, service, database, auth provider, hosting platform, or runtime.

The goal is not to block better technology choices. The goal is to make Codex explain the choice clearly enough that the user can approve or reject it.
